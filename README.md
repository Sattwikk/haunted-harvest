# 🎃 The Haunted Harvest

A responsive Halloween environment project built with semantic HTML5 and CSS3 only.

## Features
- 3 CSS-driven scenes using `:target`
- Human activity
- Animals
- Weather effects
- Moving vehicles/objects
- Halloween decorations
- CSS keyframe animation
- CSS variables
- Flexbox and responsive layout
- Keyboard focus states
- Reduced-motion support
- No JavaScript

## Files
- `index.html`
- `haunted-harvest.css`

## Run locally
Open `index.html` in a browser.

## Important
The assignment requires the stylesheet to be named exactly:
`haunted-harvest.css`

No JavaScript is used in the student project.
